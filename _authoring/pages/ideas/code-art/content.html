“Code Art”

A past concept for turning functional source code into visual and typographic art.

Concept

A past concept for treating working source code as visual and typographic art, so a program could be both functional and displayable.

Why it matters

It explored code as a creative object, turning structure and layout into part of the meaning rather than something hidden behind the result.

How it could work

The experience imagined programs arranged into shapes that reflected their purpose, such as a flight simulator shaped like an aeroplane or a trading strategy shaped like a dollar sign.

Status

Past idea from 2009.
